# Projeto CRUD de Amigos

Apresentação do projeto final desenvolvido para a disciplina de Programação WEB II.

## Sobre o projeto

O projeto apresenta um sistema de cadastro e gerenciamento de amigos, utilizando operações CRUD e sistema de login.

## Funcionalidades

* Sistema de login
* Cadastro de amigos
* Visualização dos registros
* Edição de informações
* Exclusão de registros

## Tecnologias

* PHP
* MySQL
* HTML
* CSS
* XAMPP
